# Mosaic — 習慣で写真を現像する

写真を選んで目標を決めると、写真がグレーのタイルで覆われます。
1日達成するごとにタイルが1枚ずつ外れ、期限の日に写真がどこまで現れたかが、そのまま達成度になります。

- 目標はいくつでも追加できます（上限なし）
- 期限あり → 開始日から期限までの日数ぶんのタイル
- 期限なし → 365枚のタイル
- タイルは時系列順に、左上から順番に外れます
- 入力を忘れた日は、あとから日付を選んで記録できます
- 過ぎたのに開かなかったタイルは明るいグレーになり、写真の「穴」として残ります

---

## 1. 公開する（GitHub Pages の場合）

PWAとしてホーム画面に追加するには、ファイルをネット上に置く必要があります。無料で一番手軽なのが GitHub Pages です。

1. GitHub にログインして、新しいリポジトリを作る（名前は `mosaic` など。**Public** にする）
2. `Add file` → `Upload files` で、このフォルダの中身をすべてアップロードする
   - `index.html` がリポジトリの一番上の階層に来るようにしてください
   - `icons` フォルダごとアップロードします
3. `Commit changes` を押す
4. リポジトリの `Settings` → 左メニューの `Pages` を開く
5. **Source** を `Deploy from a branch`、**Branch** を `main` / `/(root)` にして `Save`
6. 1〜2分待つと、同じページに `https://ユーザー名.github.io/mosaic/` のような URL が出ます

Netlify や Vercel を使う場合は、このフォルダをドラッグ&ドロップするだけで公開できます。

## 2. ホーム画面に追加する

**iPhone（Safari）**
1. Safari で上の URL を開く
2. 下の共有ボタン（□に↑）→ `ホーム画面に追加`
3. アイコンから起動すると、アドレスバーのない全画面で開きます

**Android（Chrome）**
1. Chrome で URL を開く
2. 右上のメニュー → `アプリをインストール` または `ホーム画面に追加`

一度開いたあとはオフラインでも起動します。

## 3. 使い方

| したいこと | 操作 |
|---|---|
| 目標を追加する | 一覧の下の「目標を追加」 |
| 今日を達成にする | 詳細画面の下の「今日を達成にする」 |
| 別の日を記録する / 取り消す | 写真のタイルを直接タップ、または「記録を修正」 |
| 目標を編集・削除する | 詳細画面の右上「⋮」 |
| バックアップする | 一覧の右上「⋮」→「データを書き出す」 |

### 画面の見かた

- 大きな数字 = **完成度**（外したタイル ÷ 全タイル）
- バーの上のシアンの縦線 = 今日の位置。線より左にバーが届いていれば、ペースどおりです
- **これまでの達成率** = 外したタイル ÷ 経過日数

## 4. データについて

記録と写真は、この端末のブラウザの中（IndexedDB）だけに保存されます。サーバーには何も送られません。

そのため、次の場合はデータが消えます。

- ブラウザの「サイトデータを削除」をした
- 機種変更した
- iOS で、そのサイトを長期間開かなかった（Safari が自動で消すことがあります）

**月に一度くらい、「データを書き出す」で JSON ファイルを保存しておくことをおすすめします。**
新しい端末では「データを読み込む」で、写真ごとそのまま復元できます。

## 5. ファイルの中身

```
index.html              画面の構造
styles.css              見た目
app.js                  ロジック（保存・タイル計算・記録）
manifest.webmanifest    アプリ名やアイコンの定義
sw.js                   オフライン用のキャッシュ
icons/                  ホーム画面のアイコン
```

### 手を入れるときのメモ

- 期限なしのときのタイル数は `app.js` の `DEFAULT_SPAN`（初期値 365）
- 期間の上限は `MAX_SPAN`（初期値 3650日 = 10年）
- 保存する写真の最大辺は `MAX_EDGE`（初期値 1400px）
- 色は `styles.css` の先頭 `:root` にまとめてあります
- **ファイルを更新したら `sw.js` の `CACHE = 'mosaic-v1'` の番号を上げてください。**上げないと、古いキャッシュが表示され続けます

タイルの配置は、写真の縦横比からタイルがなるべく正方形になる列数を選び、割り切れないぶんは「1枚少ない行」を全体に散らして吸収しています。そのため、どんな日数でも写真がぴったり覆われます（365日なら 22×17 ベースで、ところどころ21枚の行が混ざります）。
